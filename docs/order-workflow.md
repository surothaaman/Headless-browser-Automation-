
# Provider XX Order Automation
## Allconnect Order Workflow Documentation

### Screen 1: Login and Start Session

**Purpose:**
Start a new customer interaction.

**Steps:**
1. Open the Allconnect portal.
2. Authenticate using authorised credentials.
3. Locate the Start Session option.
4. Click Start Session.
5. Review the greeting screen.
6. Click Forward to proceed.

**Input Fields:**
- Username: Not documented yet
- Password: Not documented yet

**Buttons:**
- Login
- Start Session
- Forward

**Automation Requirements:**
- Open the authorised portal.
- Confirm successful login.
- Locate Start Session.
- Start a new session.
- Proceed to the next screen.
